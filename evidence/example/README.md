# Example evidence

This checked-in fixture was produced against the live local Chromium surface and synthetic portal. The discovery decisions use `ScriptedDecisionClient` so tests and reviewers can reproduce it without an API key. It demonstrates the artifact format, redacted discovery/replay JSONL, successful deterministic replay, and the `MEMBER_NOT_FOUND` business outcome.

It is intentionally not represented as the assignment's required genuine LLM discovery run. Run the `discover` command in the root README with `OPENAI_API_KEY` set, then preserve that provider-backed evidence separately.
